# students_data_visualisation_mapping
transforming raw student dataset into interactive map and visual charts

1. Data of students were collected and stored in the form of a ".csv" file.
2. The name of the file is "student_data.csv".
3. The headers include - roll number (Roll No.), Name (name), month of their birth (Birth Month), state they come from (State), height in cms (Height(cm)), body mass in kgs (Weight(kg)), their gender (Gender).
4. As this is based on an Indian dataset, the states here would mean the legislative states and union territories.
5. Name of the students were not used to map and plot data to maintain privacy.
6. The actual dataset hasn't been shared to maintain privacy.
7. Python codes are used to map and visualise data.
8. This is a part of the coursework and 5 different questions haven been answered using codes and charts.
9. 5 different directories have been created, each dealing with one of the 5 questions.
10. Each directory has 1 md file explaining the question, infereneces and explaining the charts/plots; 1 python script that generates the plots, and the generated charts/plots.
