# students_data_visualisation_mapping
transforming raw student dataset into interactive map and visual charts

1. data of students were collected and stored in the form of a ".csv" file.
2. the headers include - roll number (Roll No.), Name (name), month of their birth (Birth Month), state they come from (State), height in cms (Height(cm)), body mass in kgs (Weight(kg)), their gender (Gender).
3. as this is based on an indian dataset, the states here would mean the legislative states and union territories.
4. name of the students were not used to map and plot data to maintain privacy.
5. the actual dataset hasn't been shared to maintain privacy.
6. python codes are used to map and visualise data.
